## 调研规则包

### 角色行为边界规则包
- principles: 把性格标签转成心理动机、具体行为和场景反应；每个出场角色在本章必须有允许行为、禁止行为、语言风格和 OOC 红线；情感推进依赖共同经历、信任事件和风险代价，章节号只能作为辅助
- checks: 行为是否符合核心目标；台词是否符合角色句式和称呼；互动是否越过当前关系阶段；反差行为是否有触发条件
- blocking_rules: 冷淡/高边界角色无证据突然表白；关系角色主动依附或求助过早；角色无动机无条件信任主角

### 章节商业功能规则包
- principles: 每章至少一个明确读者收益；期待感来自目标明确、阻碍重重、奖励可期；爽点释放后必须制造新的追读问题；近五章避免重复同一种爽点
- checks: 本章小爽点是否落地；信息增量是否足以改变读者预期；冲突是否有代价、变化和意外；最后三到五段是否形成有效尾钩
- blocking_rules: required payoff 缺失；连续铺垫但没有任何释放；尾钩与本章事件脱节

### 八层模块协议规则包
- principles: 作者设定层输出不变量，下游只能引用不能擅自改写；读者期待层输出章节收益要求，不直接决定剧情；单章设计层输出章节合同，不输出空泛摘要；质量验收层优先输出阻断项、风险项和返修路径
- checks: writer_strategy 是否存在；reader_expectation_map 是否存在；chapter_contract 是否包含目标、payoff、禁区和尾钩；character_constraints 是否覆盖出场角色
- blocking_rules: 缺少章节合同仍生成正文；缺少角色边界仍写关系推进；审稿 blocking 后仍提交

### Agent 工作流规则包
- principles: 章纲先行、关键句锚定、审稿必做、中间数据持久化；RAG 和状态只提供证据，剧情决策由作者策略与章节合同决定；返修最多应回到失败层，不重跑已通过的上游层；人工确认前不得进入正式 accepted 目录
- checks: 初稿是否来自 writer prompt；review_result 是否结构化落盘；rewrite brief 是否引用具体阻断原因；commit 是否同步状态、关系、伏笔和索引
- blocking_rules: 未人工确认直接提交；写后回写失败但章号推进；隐藏/未来章节进入生成 prompt

## 写作规则

- 只写正文，不解释流程。
- 不发明新的核心点子，不把候选写成合同外的另一篇故事。
- 不新增未授权系统、数值、被动能力或力量体系。
- 结尾最后三到五段必须完成单元局部弧并落到指定结尾要求。
