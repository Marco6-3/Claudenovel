# 外部创意驱动的单章与单元剧写作实验

## 研究目标

验证不同推理时写作流程能否在不篡改人类创意的前提下，提高一个独立叙事单元的完成度。实验对象是单章、短篇或单元剧一集，不评估跨卷一致性、长期记忆召回或无人值守续章能力。

## 证据与设计取舍

- [WritingBench](https://arxiv.org/abs/2503.05244) 使用随任务变化的评价标准，说明写作评价不应只依赖一套固定泛化分数。因此每个外部创意都要携带自己的成功标准。
- [HoWToBench / Tree-of-Writing](https://aclanthology.org/2026.acl-long.317/) 把写作质量拆成树状子特征并显式聚合，报告与人类判断有较高相关性；其结果还提示堆叠更长输入不一定提高写作内容得分。因此本实验使用短创意合同和分层评分，不注入长期记忆。
- [LitBench](https://aclanthology.org/2026.eacl-long.362/) 显示通用零样本 Judge 对创意写作的人类偏好一致率仍有限，专门 reward model 也不是完美裁决。因此自动 Judge 只用于筛选和实验测量，最终结论必须保留人类偏好样本。
- [LLM-as-a-Judge](https://arxiv.org/abs/2306.05685) 与后续位置偏差研究指出位置、篇幅和自我偏好会影响裁决。因此同一对候选必须交换顺序复评，Judge 不得看到模型名、策略名和生成顺序。
- [故事候选重排研究](https://aclanthology.org/2025.in2writing-1.10/) 发现简单提示式打分与更复杂评分器的差距并不显著，同时整体故事质量仍普通。因此实验不把“更复杂 Judge”视作主要增益来源，而重点比较候选生成方法。
- [Multi-Agent Character Simulation](https://aclanthology.org/2025.in2writing-1.9/) 将角色扮演得到的 chronological fabula 再改写成叙事文本，并取得更高偏好。它对应本实验的“角色模拟 → 叙述重写”条件。
- [IBSEN](https://aclanthology.org/2024.acl-long.88/) 表明 director–actor 协作可以从用户目标生成完整戏剧，同时保持角色特征。这里借用“合同是导演、角色 Agent 只演行动”的边界，但禁止 director 自行改写用户目标。
- [专业作家使用写作助手研究](https://arxiv.org/abs/2211.05030) 指出模型难以保持作者声音，也缺乏对故事内容的深层理解；[Interaction-Required Suggestions](https://aclanthology.org/2025.in2writing-1.6/) 强调控制感与作者所有权。因此创意锁只能由人类修改，系统必须显示创意漂移证据。
- [DSpark](https://arxiv.org/abs/2607.05147) 是 token/服务层的 speculative decoding。本实验只借用“并行草拟、低成本过滤、按需验证”的调度思想，不把应用层 Best-of-N 宣称为无损推理加速。

## 核心假设

| 编号 | 假设 |
|---|---|
| H1 | 差异化 Best-of-N 相比单稿和同质 Best-of-N，提高总体偏好且不增加创意漂移。 |
| H2 | 角色模拟后重写主要提高人物因果与冲突自然度，但成本高于并行候选。 |
| H3 | 批评后重写提高合同兑现和清晰度，但可能降低语言意外性与作者感。 |
| H4 | 只提供外部创意合同的短上下文，不劣于注入历史摘要/长期记忆，并减少擅自补设定。 |
| H5 | 双顺序盲评比单次绝对打分更稳定；若顺序交换后胜者变化，自动结论应标为不确定。 |

## 外部创意合同

每个任务必须由人类或指定外部来源提供以下内容：

1. `source_text`：原始想法，原文保留。
2. `idea_locks`：不能替换的核心冲突、主题、反转、关系或结局。
3. `forbidden_changes`：明确不允许的类型迁移、价值观改写或廉价解决。
4. `freedom_budget`：允许 Agent 决定的场景、配角、视角、节奏和表达。
5. `success_criteria`：这个想法被成功实现时，读者应该看到或感受到什么。

没有 `idea_locks` 的任务不进入正式实验，因为无法区分“写得新”与“偏离人类创意”。

## 实验条件

| 条件 | 流程 | 目的 |
|---|---|---|
| C0 Direct | 单 Agent 一次写完 | 基线 |
| C1 Homogeneous-BoN | 3 个相同指令候选，匿名选优 | 测量纯采样收益 |
| C2 Diverse-BoN | 事件、人物、读者体验 3 个实现策略，匿名选优 | 测量角色差异化收益 |
| C3 Character-Sim | 角色 Agent 先按时间顺序模拟行动，叙述 Agent 再写正文 | 测量人物因果收益 |
| C4 Critic-Revise | C2 胜出稿接受一次限定批评与重写 | 测量返修收益及风格收敛风险 |
| C5 Long-Context Ablation | 在 C2 上额外注入历史摘要与长期状态 | 验证长期上下文是否反而造成漂移 |

正式比较以 C0–C4 为主；C5 是删除长期能力前的反证实验，不进入最终产品流程。

## 任务集

首轮使用 6 个外部创意，每个只写一个闭环单元：都市悬疑、家庭现实、科幻伦理、黑色喜剧、有限空间惊险、克制关系戏。每个条件对每个任务至少运行 3 次，使用相同模型、温度区间和长度预算。

## Tree-of-Writing 评价树

### A. 资格硬闸

- 所有创意锁已发生或被清晰表达。
- 未出现禁止改动。
- 核心问题在单元内部得到兑现；开放式结尾也必须完成本单元的局部弧。
- 没有占位符、元指令、候选身份或明显格式错误。

### B. 加权质量

| 一级维度 | 权重 | 二级证据 |
|---|---:|---|
| 外部创意忠实度 | 30% | 创意锁实现、主题方向、结局/反转、无擅自替换 |
| 单元叙事弧 | 20% | 建立、升级、转折、高潮兑现、余味或闭合 |
| 人物因果 | 15% | 目标、选择、代价、关系证据、行为后果 |
| 场景与语言 | 15% | 具体性、节奏、对话、叙述清晰、低套话 |
| 情绪兑现 | 10% | 情绪变化由事件支撑，高潮有真实代价或释放 |
| 原创性与意外性 | 10% | 不靠合同外反转，避免首选套路和可预测句法 |

Judge 必须先列证据关键词，再给子项分数；本地程序重算权重，不接受 Judge 自报总分。

## 盲评协议

1. 删除模型、条件、策略、生成顺序和成本信息。
2. 对每一候选对运行 `A/B` 和 `B/A` 两次评价。
3. 两次胜者一致才记录自动偏好；不一致记为 `judge_uncertain`。
4. 同时记录绝对分，但实验主指标使用成对胜率。
5. 至少 20% 的候选对由人类复评，报告自动 Judge 与人类的一致率。
6. 人类评分时先判断创意忠实度，再判断更喜欢哪篇，避免好文笔掩盖创意漂移。

## 指标与统计

- `idea_lock_pass_rate`：创意锁硬闸通过率。
- `idea_drift_rate`：出现任一合同外核心替换的比例。
- `pairwise_win_rate`：同任务、同轮次成对胜率，报告 Wilson 置信区间。
- `human_judge_agreement`：自动偏好与人类偏好一致率。
- `order_consistency`：A/B 与 B/A 判断一致率。
- `quality_tree_scores`：六个一级维度，不只报告总分。
- `cost_per_accepted_unit`：生成与 Judge 调用总量除以最终合格单元数。
- `latency_to_accepted_unit`：从条件开始到产生合格稿的墙钟时间。

任务是配对设计，条件间差异使用按任务重采样的 paired bootstrap；样本不足时只报告效应量与原始明细，不声称显著提升。

## 晋级与停止规则

- 任一条件创意漂移率高于 C0，即使总分更高也不得成为默认流程。
- 自动 Judge 顺序一致率低于 85%，先修评价协议，不继续优化生成器。
- C4 若质量增益小于 0.2/10 且原创性下降，则删除返修阶段。
- C3 若人物因果没有稳定提升，则不承担额外角色模拟成本。
- 只有同时改善人类偏好、创意锁通过率且成本可接受的条件，才进入默认写作链。
